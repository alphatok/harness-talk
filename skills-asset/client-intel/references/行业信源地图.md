# 客户研究的信源选择

按当前问题选择来源，不要求凑满固定数量。

| 问题 | 优先来源 | 边界 |
|---|---|---|
| 公司业务与产品 | 公司官网、帮助中心、开发文档 | 厂商介绍不等于独立实测 |
| 财务与经营变化 | 投资者关系、交易所或监管披露 | 保留年度、地区和指标口径 |
| 项目采购 | 客户官方采购公告、公共资源交易平台 | 核对主体、截止日和当前状态 |
| 组织与技术方向 | 公司公告、官方招聘、公开访谈 | 招聘不能证明已有预算或已立项 |
| 行业背景 | 监管部门、行业协会、研究原始报告 | 媒体和聚合平台用于发现线索 |
| 使用问题 | 有来源的用户反馈、应用商店评价 | 不能用少数投诉推断整体口碑 |

公开来源保留链接、发布日期和访问日期。多篇转载同一公告只算一条来源。关键来源不可访问时写清缺口，不凭标题补正文。

金融和法律等影响决策的内容查当前官方材料，仍保留本次分析的用途与证据边界。不得从原作者历史笔记推断本次客户事实，不自动向共享技能包回填客户数据。
