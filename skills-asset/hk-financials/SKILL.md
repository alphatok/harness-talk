# 港股财报归档｜找公告、核文件、补缺档

从港交所披露易检索港股报告，核对公司、报告期和文件类型后归档。优先官方披露；公司IR站可用于交叉核对，不把搜索不到当作文件不存在。

## 输入与开始

给股票代码、年份/期间、需要的类型和保存目录。例如：“为这家港股公司补齐最近三年的年报与中报，先核对已有目录。”代码与公司名必须一致，不能只取模糊搜索的第一项。

先查看用户指定的归档目录和已有索引，沿用现有命名。没有目标目录时，把本次文件放在当前项目下的新输出目录，不使用作者私人文件夹。财年不一定等于日历年，“最近三年”需说明包括哪些已发布报告；不要预测固定的披露日。

## 获取与核验

1. 优先使用披露易搜索页、公开披露链接或已核实的IR来源。配套脚本只提供辅助映射、清单、下载和启发式初检，接口不是稳定性承诺。
2. `map`将代码映射到公司，`list`按日期列清单。确认公司后才下载。清单达到返回上限时缩小日期窗口，不能声称已取全；不同语言可能是不同文件，按标题与内容核对。
3. 年报、中报、业绩公告与ESG报告分开。业绩公告不替代完整附注；ESG只在用户范围内下载。治理公告可登记为排除项，不额外扩充任务。
4. 下载到新文件，不覆盖已有归档。检查PDF头、声明大小、可读页数、公司、报告期及类型，必要时用现有PDF/OCR工具逐页核对。年报页数不采用固定区间。
5. `verify`仅扫描部分压缩流与关键词：通过不等于完整核验，未命中也不代表文件错误。中文字体编码、扫描件或加密PDF可能无法命中。内容核验至少确认实体、期间、类型与缺页情况，不把zlib关键词当决定性证明。
6. 索引写文件名、报告期、类型、发布日期、来源URL、大小/哈希、核验范围及未解决项。更新时只补缺，保留原始来源与历史记录。

## 脚本用法

需要Python 3标准库。以下命令在本技能目录执行；日期与代码由本次任务填写，不把示例文件当真实来源。

```bash
python3 scripts/fetch_hkex.py --help
python3 scripts/fetch_hkex.py map <股票代码>
python3 scripts/fetch_hkex.py list <股票代码> --from <YYYYMMDD> --to <YYYYMMDD> --cat financial
python3 scripts/fetch_hkex.py download <本次核对的官方PDF链接> -o <新文件路径.pdf>
python3 scripts/fetch_hkex.py verify <文件.pdf> --name <公司英文关键词>
```

官方入口：[披露易](https://www.hkexnews.hk/)。本分享版没有进行在线接口实测。接口返回变化、被限流或不可达时，说明限制并改用官方页面；不绕过权限或将旧缓存冒充最新。
