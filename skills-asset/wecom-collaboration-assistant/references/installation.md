# 安装与分享

适合直接分享完整 ZIP。安装前先识别当前AI助手及其加载规则，不默认使用Codex目录。支持原生Skill时，按该宿主当前官方说明，将完整文件夹安装为 wecom-collaboration-assistant；确保内部直接有 SKILL.md，避免多套一层。目录位置、项目级或用户级作用域及刷新方式，以当前宿主为准。已存在同名Skill时先比较版本与本地修改，再替换。

不支持原生Skill时，若宿主能读本地文件或附件，就将本入口作为任务指引，并保持scripts、references、assets等相对目录可访问；只需读取本次相关资料。需转换为宿主规则格式时，生成独立适配文件并引用本包，不覆盖既有项目规则。连文件读取也不具备时，可用当前支持的附件或粘贴方式加载必要指引，只提供实际能完成的协作。

中文展示名为“工作协作助手”，Skill标识为 wecom-collaboration-assistant。通用调用可说“使用工作协作助手，帮我……”。`$wecom-collaboration-assistant` 仅在支持这种调用语法的宿主中使用。`agents/openai.yaml` 是可选的特定宿主展示元数据，不是其他宿主的运行依赖。只安装本包不会自动联网、授权或创建资源。

## 首次安装后的提示

安装完成或首次调用时，主动展示 [使用说明中的首次提示](../assets/开始使用.md#首次使用提示)。先列本地办公能力，再介绍企微手机端授权、文档链接、PC端协作和可选消息桥接。根据本次实际检查结果，将能力标为“已就绪”“待连接”“需额外组件”或“待验证”，不能把未检查项写成已开通。

提示应包含当前AI助手名称、实际加载方式与调用词、已完成的初始化、可选能力及下一步。用户只要求安装时展示选项，不自动启动机器人、常驻服务或创建验证文档；用户已要求接入某项能力时继续完成其初始化，不重复求确认。本人扫码等必要动作一次提示一个。

本地整理需要当前助手可读取材料；XMind提取脚本还需要命令执行能力与Python3。仅做文字整理无需先安装Python。企微协作额外需要可用的企微连接器或wecom-cli与个人授权。没有命令执行能力时优先连接器，仍缺能力则提供人工步骤。不能因为提供了CLI快照就宣称当前环境已具备接口权限。

浏览器验收取决于当前浏览器工具与登录状态；桌面验收取决于当前操作系统、桌面工具和已安装应用。没有对应工具时仍可生成清单、人工执行及整理反馈。不要安装任何固定品牌 App、自动克隆代码或切换分支。

共享前确认 ZIP 不含账号信息、Cookie、授权缓存、真实客户数据或内部项目文件。本包仅携带通用指引、模板、脚本和接口参考；不预置业务目标。

## Python 技术栈

本版保留 Skill 形式。Skill 指引采用 Markdown，配套工具统一使用 Python 3.10+ 标准库，不包含 JavaScript、TypeScript 或 Node 项目，也不需要 pip 安装第三方库。

Python 负责本地解析、环境检查、参数构造、调用编排与结果核对；企微访问继续由 wecom-cli 承担。wecom-cli 自身的安装与运行要求按其官方说明处理，不能把本包称为完全不依赖 Node 或完全不依赖外部 CLI。

由助手使用已验证的 Python 解释器运行。以下以macOS/Linux常见的python3为例；Windows可替换为已验证的py -3或python。示例工作目录为本包根目录；其他工作目录使用脚本绝对路径。路径包含空格或中文时使用参数数组传入：

```text
python3 scripts/check_environment.py
python3 scripts/check_environment.py --wecom
python3 -m unittest discover -s tests -v
```

第一个命令只检查 Python；第二个只读检查 wecom-cli 版本与个人授权，不安装、不扫码、不创建文档。授权未完成时由助手继续正式授权引导。完成连接后，仍按 onboarding.md 执行“新建文档、编辑文档、回读核对”，不能把环境检查当成文档可用性验证。

检测命令不修改环境。依赖缺失或初始化失败时，按 [跨平台自适应流程](platform-adaptation.md) 查询当前官方资料并尝试补齐；优先用户目录，保留已有运行时。使用者日常仍以自然语言调用 Skill，无需手动运行脚本。
