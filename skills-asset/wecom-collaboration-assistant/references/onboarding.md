# 连接与可用性验证

## 何时执行

仅在使用者要求连接并验证企微，或已明确接受“将新建一份验证文档并编辑内容”的引导后执行。请求安装、本地整理或读取已有文件，不触发在线验证。已授权同一验证流程时不重复询问。

验证动作固定为：新建独立文档 → 编辑该文档 → 回读核对。不能用读取作者团队表替代，不能回退到任何预设链接。

## 前置检查

先按 [跨平台自适应初始化](platform-adaptation.md) 识别和修复运行条件。缺依赖时由助手查询并尝试初始化，不直接要求使用者自行配置开发环境。

优先使用当前企微连接器；缺少所需能力时读 [企微路由](wecom-router.md) 与 [创建编辑接口](wecom/smartpage-create-edit.md)。CLI 路径可运行 Python 工具 scripts/check_environment.py --wecom，只读检查版本、授权；按当前实际流程展示授权链接或二维码。一次只引导一个使用者操作，不让使用者粘贴密钥。

## 创建、编辑和核对

1. 生成中文标题“工作协作助手连接验证（YYYYMMDD HHmmss）”，以及本次随机验证标记。不包含姓名、客户或内部数据。
2. 创建一份新的智能文档。保存返回的实际文档链接。若需要恢复检查点，只保存链接、标题、标记和阶段到本地临时文件，不存凭证；不进分享包。
3. 读取新文档，取得实际主页面标识。创建和编辑必须是两次独立操作。
4. 在该页面追加一段文字：“文档编辑验证成功。验证标记：<本次标记>”。这一步验证编辑能力。
5. 回读实际页面正文，核对完整文字与本次标记。正文存于返回文件时读取该文件；仅看到成功码或页面标题不算回读通过。
6. 返回文档链接，分别报告新建、编辑、回读结果。保留这份文档，不自动删除、分享或发送给其他人。

## 异常处理

- 授权成功只代表连接可用。创建、编辑和回读分阶段判定。
- 创建超时且状态未知：先用保存的链接回读。没有链接时说明创建状态待确认，由使用者定位本次标题对应文档；定位前停止新建，避免重复创建。不得扫描并猜测旧团队资源。
- 已创建但编辑失败：保留并返回实际链接及失败阶段，不反复创建空白文档。
- 追加超时：先回读查标记，已存在则不重写；读不到或读取失败时保留待确认，不盲目重试。
- 无权限：报告缺少的能力及失败阶段，不改共享权限、不伪造通过。

本验证只证明本次账号能新建和编辑这份智能文档。访问其他文档、智能表格写入、目标 App 操作及业务流程仍需在对应任务中核验。
