# 接口资料来源与范围

此包基于使用者提供的0.2.1版 Skill 做通用化，版本0.4.0，展示名“工作协作助手”，配套工具采用 Python，保留 wecom-cli 依赖。智能表格、联系人和媒体接口文件沿用原包的参考快照；文档新建与编辑部分根据本次可用的企微智能文档接口说明整理，日期2026-10-21。跨平台版补充运行时适配、自适应初始化流程与离线回归验证。

这些是随包接口资料，不代表当前机器已经安装 CLI、完成授权或验证线上接口。CLI 参数发生变化时先查当前 help 和正式说明。不得把作者机器上的成功记录作为接收者环境的验证结果。

已移除原包的固定团队目标、人员模块映射、固定用例范围和品牌 App 安装/仓库发现脚本。保留通用 XMind 原文提取，以及要求明确目标和范围的可选智能表格结果初始化器。桌面和网页验收由当前环境可用工具或人工指导完成。

本版实际检查范围见 [离线验证记录](delivery-check.md)。
