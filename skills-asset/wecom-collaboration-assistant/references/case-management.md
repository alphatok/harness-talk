# 用例管理

## 从业务材料形成清单

保留来源路径、原编号、分组和备注。XMind 使用 scripts/extract_xmind.py INPUT --out OUTPUT，输出原文树和 Markdown。脚本不会覆盖已存在输出。附件、图片和链接若未解析，列为待补充，不伪造图中内容。

整理为场景、前置条件、操作步骤、预期结果。补充边界、异常与权限场景时标明“建议补充”，不要混入原文。编号缺口不自动补齐。计数区分原始节点、可执行用例及建议新增项。

负责人按用户明确分工填写；联系人查询只能解决身份，不能推定责任。避免把原作者、反馈人直接当负责人。

## 选择交付目标

本地 Markdown 可独立使用。新建在线验收文档适合叙述流程与问题；智能表格适合多人协作、筛选与状态统计。用户已指定类型时沿用。在线目标来自本次明确链接或明确创建指令，没有目标时不读取任何默认团队资料。

已有表先读字段、选项和记录，再映射。本包八列是新建结果表的可选简洁模板：产品/模块、用例编号、用例名称、执行人、执行时间、测试结果、实际结果、测试证据。现有表可保留自己的字段与状态，不强制八列。

初始化保持未执行；执行人、执行时间、实际结果、证据留空。写入按稳定编号查重，保留已有结果。一次任务若需多轮执行，按既有轮次或新增独立执行记录保存，不覆盖历史。

## 可选初始化脚本

scripts/initialize_results.py 只适用于 assets/table-schema.json 的八列模板，且源表的模块字段为单选。结构不兼容时停止使用该脚本，转用当前接口按原表维护，不能删字段来迁就脚本。

由助手在合适的本地 Python 环境执行：

```text
python3 scripts/initialize_results.py --target-url 本次明确的智能表格链接 --case-ids CASE-01 CASE-02
```

默认仅预览。实际写入需本次任务已授权目标和范围，再添加 --apply。用 --all-cases 可显式选择全部源用例；不能与 --case-ids 同用。可用 --source-sheet、--result-sheet、--module-field 指定本次表名与模块字段。所有参数按 argv 数组传入，不能拼接未转义的 shell。

源表和结果表位于同一明确指定的文档。无目标或无范围时会在调用企微前停止。只追加缺少编号的未执行记录；保留现有结果。已有结果表的视图默认不改。--configure-standard-views 会配置“按模块查看”“失败与阻塞”两个同名视图，使用前须确认本次任务包含此变更。新建结果表时建立这两个视图并回读。

脚本有界读取源表和结果表各少于1000行，单次最多追加100条。超限或权限不兼容时停止，不默默处理部分数据。SQL 查询接口不可用时按随包读取接口降级，由助手完成有界查重；脚本本身不自动绕过权限。

预览也检查现有结果表选项与追加上限。列表分页未读完、响应缺少values/rows、返回文件路径或结构不符时停止，不按空表处理；转用当前接口按范围完整读取后再规划。默认源表的单选字段为“产品/模块”；已有表按实际字段映射，不自动改名。

写入返回后回读条数、编号、状态及关键字段。请求超时或返回不可解析时先核对目标，不能直接重复新增。无需初始化时不用运行此脚本。
