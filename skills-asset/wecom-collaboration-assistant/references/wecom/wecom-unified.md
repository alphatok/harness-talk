# 企微协作通用检查

本文件只服务本包的验收文档、智能表格、联系人解析和证据上传。不是其他办公动作的授权来源。

只在选择企微流程后检查连接。已有连接器按其当前工具说明操作。使用 CLI 时先查看 wecom-cli --version，要求不低于1.2.1；再用 wecom-cli auth show --status 检查授权状态。未授权时按当前 auth help 的正式初始化流程提供授权链接或二维码；支持时可用 auth init --noninteractive。不要让使用者提供 Cookie、Token 或密钥。CLI 不存在或版本过低时按当前官方安装说明处理，不捏造下载地址。

授权完成后还要核验本次文档操作权限。不要把 CLI 安装、账号授权、文档读取和文档写入混为同一成功状态。只有业务执行确需本人身份时才读取当前身份；不将身份原始响应和内部标识复制进交付物。

外部变更受本次任务授权约束。写后回读；不自动扩大分享范围、不通知联系人、不发送消息。未知状态先核对再重试。上层流程没有指定目标时，不从本机配置或示例中猜测项目文档。

按 [路由](../wecom-router.md) 阅读对应接口。快照中出现但本包未提供的其他技能路径不是安装依赖；当前流程需要缺失能力时明确说明或使用已具备的合适工具。
