# 工作协作助手 · 使用说明

适用对象：运营、销售、产品、客服、实施、测试及其他需要办公协作的同事。
版本：0.4.0（跨平台自适应版）。Skill 标识：wecom-collaboration-assistant。

配套脚本使用 Python 3.10+；企微能力继续依赖 wecom-cli 与个人授权。保留 Skill 使用方式，普通同事无需写 Python。

本地整理与CLI流程适配macOS、Windows、Linux。缺依赖或遇到其他平台时，助手会识别环境、查官方资料、尝试初始化并复验。个人扫码和系统权限限制会给出具体操作。桌面自动操作取决于当前工具；缺少时可继续人工验收。

## 安装

将完整包交给当前AI助手，说明“安装并使用工作协作助手”。助手会先检查自身的Skill或文件加载能力，再选择实际安装目录或适配入口，不默认使用某一客户端的目录。目录内应直接包含SKILL.md。不支持原生Skill时，可通过文件、附件或项目规则加载本包指引；自动执行范围取决于当前工具。不要把个人账号、授权文件或项目数据加进分享包。

安装后，按当前助手的加载方式开始任务。命令和文件操作由具备相应能力的助手处理，使用者不用照抄终端命令。下面示例采用通用自然语言调用；支持`$`语法的宿主也可用`$wecom-collaboration-assistant`。

## 首次使用提示

首次安装后，助手先说明当前宿主、加载方式、可用工具与调用方法，再介绍以下能力，并说明哪些已就绪、哪些还需连接或额外组件：

| 能力 | 可以怎样使用 | 启用条件 |
| --- | --- | --- |
| 本地办公 | 整理资料、编写文档、维护表格、拆解任务与跟进进度 | 当前工具可读取材料；专用文件格式按实际工具支持处理 |
| 企微手机端授权 | 用手机企业微信扫码，或按当前授权页面完成个人授权 | 可用连接器或CLI提供真实授权链接或二维码；需本人操作 |
| 企微文档链接 | 将手机端或PC端复制的文档、智能表格链接交给助手，读取、整理或按要求更新 | 对应文档权限及已连接的企微工具；其他文档类型按当前能力路由 |
| 企微PC端协作 | 在PC端打开交付链接查看或继续编辑；需要界面操作时由助手协助 | 文档访问需登录和权限；自动操作PC界面还需本机桌面工具，单独检查 |
| 手机发指令、电脑侧处理 | 在手机或PC企微群内@机器人，将请求送到电脑侧AI助手，回复返回原会话 | 适配当前AI助手的消息桥接组件、机器人配置与独立接入验证；本包不内置常驻消息服务 |
| 跨平台初始化 | 识别系统，查当前官方资料，尝试补齐依赖并复验 | macOS、Windows、Linux按实际环境处理；其他平台先探索可用方案 |

手机扫码授权只用于开通工具访问；从手机聊天远程发指令还需消息桥接。企微PC端登录也不能替代CLI授权。优先检查当前AI助手已有的集成或适配组件。Codex可选用`wecom-codex-bridge`，该组件已知仅有macOS自动安装流程；其他助手或Windows/Linux需核查当前可用方案并尝试适配，不套用其他宿主的聊天绑定或系统服务命令。

本地消息桥接需电脑保持运行、联网，目标AI助手处于可处理状态。接通后分别验证接收、投递与回复；没有实测就标待验证。新增组件的安装与接入由使用者明确选择后启动，已有授权范围无需重复确认。

可以直接说：

> 连接我的企微，先带我用手机完成授权，再核对这个文档链接是否能读写。

> 我想在手机企微里@机器人，让电脑上的AI助手帮我处理工作。先检查当前助手的桥接能力，缺少时查官方方案并尝试初始化。

> 在企微PC端打开这份工作文档，帮我检查当前能否协助操作界面。

## 直接复制使用

**检查并初始化当前电脑**

> 使用工作协作助手，识别我的系统，检查运行条件。缺依赖时查当前官方安装方式，尝试在用户目录初始化，再验证。先启用本地整理；需要企微时再连接。

**先整理，不连企微**

> 使用工作协作助手，按这份活动方案整理上线验收清单。区分正常流程、异常情况和待确认项，先输出本地草稿。

**连接并验证企微**

> 使用工作协作助手，连接我的企微，并新建一份验证文档、编辑内容、回读核对，告诉我各步骤是否成功。

连接时按提示完成个人授权。只有启动该验证流程，才会创建一份独立的验证文档。不会打开任何预设团队文档。创建后会保留链接；不会自动删除或扩大分享范围。

**协作验收**

> 使用工作协作助手，把这份销售流程整理成验收清单，新建一份企微验收文档。负责人没有依据的先留待确认。

> 使用工作协作助手，把这份 XMind 整理到我提供的智能表格，只处理本次选定用例，保留已有测试结果。

**执行与复测**

> 使用工作协作助手，一步一步带我验收这个页面。我来操作，你帮我记录结果；缺证据的先标待确认。

> 使用工作协作助手，按这份问题记录做复测，保留原失败情况，整理修复后结果和剩余风险。

## 能带来的好处

- 从现有材料生成可操作清单，减少遗漏和重复整理。
- 统一预期、实际结果与证据，方便不同部门核对问题。
- 保留原失败与复测结果，便于交接和追踪。
- 可先本地使用，再按需接入企微；每位使用者使用自己的授权与目标。

这些是流程收益，不承诺固定节省比例，也不替代使用者的业务判断。
