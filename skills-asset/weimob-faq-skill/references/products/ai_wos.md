# WOS与历史AI名称

核验日期：2026-10-22。旧资料中出现的名称仍需按原文语境辨认。

| 名称 | 已核实的公开定位/历史 | 回答边界 |
|---|---|---|
| WOS | 2022年发布的新商业操作系统；官网介绍应用、开放及扩展能力 | 是能力底座；不能代指某一AI应用，也不意味着任意ERP零成本直连 |
| WAI | 2023年发布；独立官网仍展示商城搭建、创作、AI试衣、导购及经营Agent | 当前新产品介绍优先使用星元等产品页；未找到足够明确的官方更名公告，不武断宣称WAI已全量更名、停服 |
| WAI Pro | 官方页仍称企业个性化AI定制解决方案 | 星程同有定制定位；没有核实一对一更名关系，不直接写成WAI Pro=星程 |
| WIME | 集团历程记载2024年推出面向C端的AI产品 | 不把WIME和星创WIMO视为同名或已确认升级关系 |
| Genstore.ai | 集团历程记载2025年战略投资 | 投资关系不等于微盟SaaS内置模块，也不等于所有产品均已在国内商家环境开放 |

媒体出现“WAI升级星元”等表述，可作为查证线索；若用户问迁移、账号兼容或旧套餐继承，必须进一步查正式公告或向服务方确认。

WAI当前页展示AI试衣，说明这类能力已出现在官方公开介绍中。它不是衣物尺码精度或退货下降幅度的保证；支持的商品、终端和套餐需核对。不要沿用宣传中的固定秒数当响应承诺。
