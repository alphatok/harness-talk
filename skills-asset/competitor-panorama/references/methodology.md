# 端到端方法论详解

## 方法论总纲

三层递进 + 一条主线：

1. **业务架构**（角色 × 触点 × 价值链闭环）——回答「生意怎么转」
2. **产品架构**（分层堆叠 + 数据回流/行动回投双脊柱）——回答「产品怎么承载」
3. **模块能力地图**（域 × 模块矩阵 + GOLDEN PATH 主链路）——回答「每段链路靠哪些模块撑住」

主线是端到端价值链：**数据汇聚 → 营销获客 → 商机销售 → 交易履约 → 服务留存 → 分析决策**（针对目标公司可替换链路节点，但必须成闭环：分析/Agent 行动回投业务）。

## 阶段 0：确定范围与计划

计划书要素：

- **范围**：目标公司、分析截至日期、交付路径（本地 HTML）
- **参考结构**：参考报告文件路径；本次复用其结构，替换其内容与品牌色
- **白名单**：目标公司官方域清单（模式见 source-whitelist.md）
- **采集范围**：业务、应用产品、数据与 AI，各自保留事实与来源
- **标准**：★判定标准（去掉它链路即断）、模块粒度（一个 mrow 一个模块）
- **QA 标准**：结构校验命令 + bbox 脚本 + 渲染巡检
- **风险**：财务披露口径变化、品牌迁移、定价不公开等预期风险与对策

## 阶段 1：官方源采集

| 路 | 范围 | 产出样例 |
|---|---|---|
| ①业务架构与财务 | 公司定位、客户数、财报（10-K/季报/中期）、分部收入、ARR、RPO、区域、品牌迁移 | working/xx-business-architecture.md |
| ②应用云产品 | 各产品/云的功能模块、版本与定价阶梯、标准对象/API 版本、行业模板 | working/xx-application-clouds.md |
| ③数据·AI 平台 | 数据平台能力组、AI/Agent 产品构成与定价、运行时观测、生态 | working/xx-data-ai-platform.md |

采集协议：

- 仅限白名单域名；每条事实写成 `事实 | 来源URL | 访问日期`；各类 URL 汇总后去重，统计总条数（用于 masthead「官方来源 N 条」）
- 每类资料整理结束时列出「存疑清单」：口径冲突、定价缺失、无法确认的 GA 状态——供阶段 2 与页脚「未确认项」使用

## 阶段 2：交叉验证

- 数字互验：收入、ARR、客户数等必须多源一致；不一致取证据优先级更高者并记录
- 命名对齐：全部用当前官方名（品牌迁移后新名为主、旧名括注）
- 口径审查：分段披露切换、ARR 口径扩容、AWU 覆盖范围变化 → 生成「口径警示」写入报告脚注
- 反面审查：官方不存在的产品名/能力名一律剔除（如 Slack Protect、Apollo 这类 AI 臆测名）

## 阶段 3：合成

1. 先盘点模块清单（D1..Dn × M1..Mn），后推导 GOLDEN PATH
2. **GOLDEN PATH 推导法**：把阶段 0 定的价值链六节点逐一映射到模块清单——每个节点挑出「去掉它链路即断」的模块，按链路顺序串成 8 节点左右的主链路（首尾用 ★）
3. HTML 合成顺序：CSS 设计系统 → masthead → Section 01 业务架构 → Section 02 产品架构 → Section 03 模块地图 → footer 数据口径（结构规范见 report-spec.md）
4. 每写完一个 Section 跑一次结构校验，最后跑 bbox 脚本 + 整页渲染

## 阶段 4：收尾与汇报

- 整页截图巡检：文字溢出、坐标碰撞、chips 重叠
- 页脚口径逐条核对可溯源
- 汇报：交付路径 + 域/模块/★计数 + 官方来源条数与访问日期 + 关键口径警示 + 未确认项清单

## 定价信息的处理

- 只用官网列表价，标注「未含折扣与税费」
- 版本阶梯用表格或 chip 标注（如 Starter → Pro → Ultimate / 专属版）
- 不公开的定价（如部分企业版）→ 未确认项，绝不拍脑袋写数字

## 财务分析的固定关注点

- 总收入、订阅占比、分部/分段披露结构及其**变化**
- ARR/Agent 相关新口径（注意扩容警示）、客户数口径（如 ≥$1m ARR 分层）
- RPO / cRPO（剩余履约义务）作前瞻指标
- 中期目标（如 FY30 收入目标）单列为「官方目标」不混入已实现数据
默认串行完成。用户明确授权并行代理工作后才分派；未授权时按相同主题顺序采集。计划可直接执行，只有用户要求先审计划时等待确认。财报优先用于财务，帮助中心与开发文档优先用于功能边界，不能以一条全局排序覆盖所有问题。官方未披露财务时注明未查到公开财报，不能推断其上市状态。
