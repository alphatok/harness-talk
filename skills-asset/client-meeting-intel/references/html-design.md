# 输出 HTML 设计规范（html-design.md）

> 模板（templates/*.html）已内嵌全部 CSS/JS——优先复用设计与交互，必要时可裁剪；修改后重新核对锚点和布局。本文件回答两类问题：① 想在骨架里新增组件时怎么写；② 每次生成时如何保持质量底线。

## 1. 模板色板

**规则：**
- 状态色不得单独表意——必须带图标或文字（如 ⚠️ + 文案），且不得复用为「系列第 N 个」。
- 文字永远用墨色系（主/次/弱），不用系列色做文字（数值除外，如大数字可用系列色强调）。
- 信号色固定语义：痛=红、赞=绿、要=黄、向=蓝、决=紫、竞=橙、关=绿——七个信号块图标背景与模板一致。

## 2. 深色 / 浅色双模式（模板已实现）

- `:root` 定义浅色；`@media (prefers-color-scheme: dark)` + `:root[data-theme="dark"]` 定义深色。
- 页面右上角固定切换按钮：`onclick` 切换 `document.documentElement.dataset.theme`。
- 深色值是从同一色板为深表面选出的，不是自动翻转。
- 打印时强制浅色：`@media print` 中 `body { background: #fff }` + 继承浅色变量。

## 3. 打印规范

- `@page { size: A4; margin: 12mm 11mm; }`
- 长文分页：`section.pb`（break-before: page）用于大节换页；`.avoid-break` 用于表格/图表块防跨页。
- 所有 HTML 必须 `⌘P` 可导出干净 PDF——生成后建议检查一次打印预览中的分页与标签重叠。
- 屏幕端折叠内容在 `beforeprint` 时自动展开，`afterprint` 恢复原状态；不得删除模板中的打印事件脚本。

## 4. 自包含与可移植

- 全部 CSS/JS 内联，零外部依赖（无 CDN、无外链字体、无网络请求）——客户现场无网可打开。
- 字体栈：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 数字列用 `font-variant-numeric: tabular-nums`（评分表对齐）。

## 6. V2 信息架构与密度规则

### 6.1 三层阅读路径

- **30 秒**：分析报告读 01；推进策略读 01 + 05。
- **5 分钟**：分析报告读 02 + 08 + 09；推进策略读 02 + 03。
- **完整复盘**：阅读证据、评分、路线、风险与待确认项。
- 阅读提示放在头部元信息之后、正文导览之前；不得用空泛文案替代明确章节指引。

### 6.2 导览与锚点

- 分析报告固定使用 `s01`—`s10`；推进策略固定使用 `p01`—`p05`。
- 每个 id 全文唯一，目录 href 与 id 必须一一对应；不得生成失效锚点。
- 桌面端目录宽约 210px 并 sticky；正文最大宽约 920px。移动端目录变为横向滚动吸顶条，不允许撑宽页面。
- 保留 `IntersectionObserver` 能力检测；不支持时至少保持首项高亮和锚点跳转可用。

### 6.3 可读性与折叠

- 页面标题约 32px，章节标题约 22px，正文约 13.5–15px，正文行高不低于 1.65。
- 长引语中的说话人/强度/时间属性另起一行，避免挤在正文末尾。
- 不删除信息以换取“清爽”；用分组、留白、折叠和阅读路径降低认知负荷。
- 分析报告 7 个信号流全部保留，默认展开前 2 组；推进策略事实/预期/决策与协作 3 组全部保留，默认展开事实层。

### 6.4 响应式与验收

- 约 900px 以下切换单列主体与横向目录；约 560–600px 以下将卡片、路线、风险和行动布局降为单列。
- 页面级必须满足 `body.scrollWidth === body.clientWidth`；目录内部允许横向滚动。
- 浏览器至少检查一次桌面宽度约 1280px、移动宽度约 390px、深色切换、目录跳转、折叠状态和控制台错误。
- 静态检查只能证明结构与脚本可解析；不得把静态检查写成视觉验收。

## 7. 图表规则（如需在骨架外新增图表）

- 新增图表按本次内容与当前工具实现，无需额外安装技能。
- 单轴原则：不用双 y 轴；两个不同量纲的度量 → 两张图。
- 图例常驻（≥2 系列必须有图例），≤4 系列可直标。
- 系列色按固定顺序分配，不循环、不按排名变色。

## 8. 文件命名与落盘

- 分析报告：`{客户}-会议情报分析报告-{YYYY-MM-DD}.html`
- 推进策略：`{客户}-推进策略与追问清单-{YYYY-MM-DD}.html`
- 落盘：默认当前工作目录；用户有 `clients/{公司}/` 结构时放入其中（遵循本次目录约定）。
- 多场会议迭代：文件名带新日期，旧文件保留（保留旧版本）。
