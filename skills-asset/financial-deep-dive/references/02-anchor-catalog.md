# 交叉核验目录

旧称“不可变锚点”仅为文件命名。以下数字仍可能重述、估计或受时点影响。

| 检查项 | 联读资料 | 常见误读 |
|---|---|---|
| 利润与经营现金流 | 现金流调节表、营运资本附注 | 单期背离直接等于收入不实 |
| 应收与减值 | 账龄、回款、信用政策、组合假设 | 账龄拉长只可能由放宽信用引起 |
| 现金与负债 | 现金等价物、受限存款、借款与担保 | 所有现金可自由使用，或重复扣减质押 |
| 税费 | 当期/递延所得税、实缴税、税率调节表 | 用有效税率直接反推现金纳税利润 |
| 收入确认 | 合同、履约义务、主要责任人/代理人判断 | 收入与流水比率变化直接证明总额法切换 |
| 合同负债 | 余额调节、新增预收、收入转结 | 全部已收现金或未来收入保证 |
| 员工与薪酬 | 平均/期末人数、地区、外包及股权激励 | 薪酬除期末人数即精确人均成本 |
| 研发与资本开支 | 开发支出、费用化、无形资产和摊销 | 资本化一律等于操纵利润 |
| 分部及经营指标 | 分部重组、ARPU、客户数定义 | 跨年定义相同无需核对 |
| 审计及重述 | 审计意见、关键审计事项、重述说明 | 关键审计事项等于舞弊或审计否定意见 |

使用一组独立证据评估假设；多条来自同一管理层口径的信息不能当成多份独立证据。
