# 借鉴 3Blue1Brown 的讲解方法

用于建立直觉、理解机制或展开推导。以下是实践归纳，不是官方定义，也不强制按六个环节写成六段。

## 设计讲解

| 环节 | 设计问题 | 可用做法 |
|---|---|---|
| 明确问题 | 读者要理解什么，卡在哪里？ | 用一句问题或结论限定范围 |
| 建立具体模型 | 抽象概念对应什么可观察对象？ | 数字例子、几何图形、状态或业务场景 |
| 引导预测 | 哪个变化能检验当前直觉？ | 改一个条件，邀请判断结果 |
| 展示变化 | 哪一步让结果发生变化？ | 连续变形、中间状态、前后对照 |
| 引入抽象表达 | 术语或符号与对象怎样对应？ | 对象、标签、公式逐项对应 |
| 检验与划定边界 | 能否换例子解释？什么时候不成立？ | 新例、反例、边界值和适用条件 |

先给核心结论或学习目标，再展开。用户已掌握的基础可跳过；面向熟练读者，可以公式起步，再补直觉。不要求每次都预测、类比或出题。

预测问题可以连同结果交付，不默认暂停等待回复。涉及用户真实选择或必要信息时，按任务规则提问，不能用预测题代替澄清。

## 具体模型与抽象之间

- 指明例子中的对象分别代表什么。同一对象在文字、画面和公式中的含义保持稳定。
- 一次突出一个关键变化；必要的关联变化可以一起显示，但写清关系。
- 颜色、位置和形状用于保持对应，同时提供标签或其他提示，不能只靠颜色辨认。
- 类比是辅助模型。说明适用范围，不能把类比观察当作原命题的证明。
- 新例子必须有依据；自造数字标明教学示例，不伪装成实测或业务数据。
- 公式前后都解释关键量的意义。熟悉符号的读者无需逐个重复定义。

## 示例：梯度下降

任务：解释步长为什么影响梯度下降。以下为教学示例。

先限定：在函数 f(x)=x² 上，观察固定步长 α 的更新 x_next=x−α·2x。此例的结论不直接推广到任意函数。

1. 在曲线上标出 x=2，对应函数值4。用箭头表示当前位置的导数2x=4。
2. 预测 α=0.25 时下一步的位置，再计算 x_next=1，函数值1。
3. 保持起点不变，将 α 改为1。下一步到−2，之后在2与−2之间振荡，函数值不下降。
4. 对应公式 x_next=(1−2α)x：步长通过这个倍数改变位置。
5. 换起点检查；对本例，0<α<1 时位置收敛到0。α=1且起点非零时持续振荡；α>1且起点非零时绝对值增大。

可以用文字计算、前后图、可调步长的交互页，或逐步动画表达。形式按理解障碍选择，不自动要求视频。

边界：这个凸二次函数具有明确的全局最低点。它的演示不能证明一般非凸函数会收敛，也不能证明一定找到全局最优。

## 不适用的情况

安装步骤、错误处理、进展报告和紧急操作通常直接给动作、条件和状态。不要为套用讲法而隐藏步骤、延迟结论或编造探索过程。
