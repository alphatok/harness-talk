# 跨形式验证与案例检查

复杂交付物按相关项目检查。默认内部执行；用户要求报告或存在影响使用的限制时才展示。

## 内容、运行与理解分开核对

| 层面 | 通过依据 | 不足以证明通过的证据 |
|---|---|---|
| 信息保真 | 原文或可靠来源与正文、图、公式、旁白逐项一致 | 语言流畅、配色一致 |
| 数学与模型 | 公式适用条件成立，手算值和边界值符合推导 | 曲线看起来合理 |
| 运行与呈现 | 实际渲染、操作或播放，检查相关状态 | 代码可解析、渲染命令退出成功 |
| 模型自检 | 能从成果中定位读者问题的答案及边界 | 模拟读者评分 |
| 真实读者验收 | 目标读者独立复述、预测或执行，结果有记录 | 作者认为好懂、另一模型赞同 |

中文复杂任务可复用已安装 plain-chinese 的质量检查；缺少时按下文完成双向保真与真实读者边界检查，不停止任务。

本技能另查视觉与模型：箭头是否暗示无依据因果；简化图是否丢掉关键分支；参数范围是否超出公式定义；示例是否被当作真实数据；动画中间状态是否造成错误概念。

未执行的层面如实标注。没有目标读者参与时，真实读者验收为“未进行”，不计为失败，也不能报告通过。

## 行为检查案例

以下输入用于检查技能决策，验收看行为与不变量，不匹配固定措辞。示例数字均为教学数据。

| 输入任务 | 预期行为与通过条件 |
|---|---|
| 用两句话解释什么是缓存 | 直接文字回答，不自动生成图或文件，不硬塞预测题 |
| 改写：安装完成后启动服务；只有端口冲突时才修改端口 | 保留先后与条件，不把修改端口写为每次必做，不套发现式叙事 |
| 画申请流程：材料完整才进入审核，否则退回补充 | 图文一致，两个分支完整，不能推断审核通过或自动批准 |
| 用交互页展示 f(x)=x² 的梯度下降步长 | 模型标为教学示例；更新式为 x_next=(1−2α)x；默认与边界正确；实际操作控件后核对结果 |
| 解释上述函数中 x=2、α=0.25 与 α=1 的差别 | 前者下一步1；后者下一步−2且持续振荡；不能声称步长越大下降越快 |
| 将“可能改善，尚未验证”改成中文旁白 | 不升级为已改善，不编造实验和视频检查，不因句长删限定 |
| 只设计90秒视频，先给分镜 | 只交设计，时长为目标估计；不渲染，不宣称成片已生成 |
| 制作实际视频解释梯度下降 | 衔接可用制作技能；实际成片和媒体检查，或具体阻塞；分镜不能替代成片 |
| 页面可以运行，是否说明用户已经理解 | 区分运行与理解；没有真实读者记录时不得报告理解验收通过 |
| 用同一内容逐级演示 | 各形式事实、参数、范围一致，不为突出效果故意写差基线；说明成片与分镜差别 |

## 真实理解验收

按读者与用途设定任务。概念解释可用：

- 用自己的话解释核心机制和适用条件。
- 改变一个关键条件，预测结果并说明原因。
- 面对新例或反例，判断原结论是否成立。

是否需要这些任务由用途决定。预先记录通过条件、材料版本、读者角色与协助情况。技能不自动联系他人。一次验收只支持该次读者与任务的结论。
