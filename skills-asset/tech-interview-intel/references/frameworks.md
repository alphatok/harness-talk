# 前沿技术采访 · 六层分析框架（Tech Interview Intel）

每层产出都要能回答同一句话：**「若为真，对我关心的事有什么不同？」**。分析不出这句话的内容，宁可不收。

---

## L1 信号三分类（地基：引语入库前先过三轴）

| 轴 | 分类 | 记号 |
|---|---|---|
| 信息类型 | 事实（做了什么/数据）· 观点（怎么判断）· 预测（会怎样）· 愿景（该怎样） | 事 / 观 / 预 / 愿 |
| 证据等级 | 一手（我做的/我亲眼见的）· 二手（别人告诉我）· 推断（类比/顺口说，无依据） | 一 / 二 / 推 |
| 共识度 | 主流共识 · 非主流但具体 · 非共识且反直觉 | 共 / 非 / 反 |

每条入库引语标三记号，例：`[预·一·反]`。**共识度判定要给依据**（相对谁的共识：行业公开叙事、他所在圈子的共识、学术共识——分层写）。

口语置信信号（文字转录可用）：笃定断言 vs 「可能/大概/不清楚/还在想」——后者集中出现处常是**受访者能力边界或尚未想透的地方**，进 L6。

## L2 非共识 2×2 矩阵（核心头牌）

```
              ← 可证伪程度高（具体断言）       可证伪程度低（口号叙事）→
  共识度 ┌──────────────────────────┬──────────────────────────┐
  高     │ Q2 基线事实               │ Q4 噪音客套               │
  (主流) │ 可信但人人会说，无超额收益  │ 丢弃；最多一句带过        │
        ├──────────────────────────┼──────────────────────────┤
  低     │ Q1 核心情报 ★            │ Q3 愿景叙事               │
  (非共识)│ 最值钱：他信别人不信，且具体 │ 观察不下注；记录但不进账本  │
        └──────────────────────────┴──────────────────────────┘
              (横轴：可证伪性 · 纵轴：共识度)
```

**Q1 情报卡六要素**（缺一不可）：
1. **观点原话**（逐字，带出处定位）
2. **证据等级**（一眼看出他凭什么这么说）
3. **下注立场**（他押了什么？创始人卖叙事、投资人讲仓位、研究者护学派——立场即风险敞口）
4. **可证伪判据**（出现什么现象=对；出现什么=错）
5. **若为真的含义**（市场规模/竞争格局/技术路线哪一个会变）
6. **对谁重要**（投资人/创业者/工程师/产品 逐一代入）

Q1 收满 3 张以上时排序：**可证伪性 > 若为真的影响面 > 与主流叙事的背离度**。

## L3 可证伪分级 + 预言账本条目

| 档位 | 判据 | 去向 |
|---|---|---|
| **强可证伪** | 有时间（或时间窗）+ 量纲 + 判据 | 进账本「强」 |
| **弱可证伪** | 有方向、无时间或无量纲 | 进账本「弱」 |
| **不可证伪** | 无判据、纯口号（如「AI 将改变一切」） | 只进 L2 矩阵 Q3/Q4 或叙事层，不进账本 |

账本条目固定字段：`编号 P#### · 日期 · 来源文件 · 受访者 · 主题标签 · 档位（强/弱）`，正文：预测原话（逐字+出处）→ 判据（出现什么=对/错）→ 预估验证时间 → 状态（待验证/已验证✓/已证伪✗/已过期）→ 验证记录（日期+结论+依据）。

## L4 思维模型与 Pattern

**思维模型**：
- 显式：受访者明说的原则/框架（如「第一性原理」「复杂度守恒」）——记原话+他如何应用
- 反推：从其决策倒推的隐性规则（他做了什么取舍=他信哪条规则）——记「行为 → 反推规则 → 适用边界」，必须标「（反推，推断）」

**Pattern 四层**：
- 技术架构 pattern：tradeoff 选择（先进 vs 可用、中心化 vs 边缘、通用 vs 专注）及理由
- 商业模式 pattern：定价逻辑、生态位、GtM、单位经济
- 认知叙事 pattern：行业隐喻的演化（如「电力→算力」类比被谁在用，说明什么阶段）
- 反模式：受访者自曝踩过的坑（什么做法错了、为什么会错）

**透镜库**（按访谈主题适配取用，不硬套）：
1. 单位经济（每个用户/每次推理的成本结构与盈亏点）
2. 护城河类型（数据/网络/转换成本/规模，选哪种、为什么）
3. 内外观视角（内部视角 vs 基准率：这类预测历史命中率是多少）
4. 技术采用曲线（这项技术在 crossing the chasm 的哪一段）
5. 复杂度守恒（复杂度不会消失只会转移——他把复杂度转移给谁了）
6. 标准战争（是否在争事实标准/接口标准，各方筹码）
7. 反脆弱（他的方案在失败时是存活还是归零）
8. 二阶效应（他说的一阶结果，二阶/三阶是什么）
9. 幸存者偏差自查（他的成功叙事里被漏掉的失败样本）
10. 叙事隐喻（他用什么类比讲技术——类比本身暴露他对该技术的理解框架）

## L5 垂直主题分析

- **主题地图**：本次访谈涉及的领域骨架——谁在做、卡点、生态链角色与依赖（抽结构，不抄产品名）
- **分歧点清单**：受访者主张 vs 行业主流，分栏对照；访谈内立场与外部补充知识分开标注
- **成熟度判断**：demo 期（能演示不能规模）/ 工程期（可规模但贵）/ Scale 期（成本塌缩中）/ 衰退期，用访谈内证据支撑

## L6 盲区与追问

- **回避信号**：被追问时转移话题、含糊、答非所问——逐条记发生时点
- **该问没问**：采访者没问、但我们认为关键的问题清单（≤7 条，每条一句为什么关键）
- **能力边界**：哪块懂、哪块明显外行 → 相关结论自动降权，报告中标注

## 决策相关性（收口）

四视角各一小节，格式统一：`若 L2/L3 的结论为真 → 该做什么（或停止做什么）`。
- **投资人**：仓位、赛道判断、需要跟踪的验证信号
- **创业者**：路线取舍、竞争位、可抄的模式
- **工程师**：技术选型、该学/该弃的栈
- **产品**：用户价值主张、该借鉴的交互与边界

## 迭代对比（多次采访）

同受访者对比维度：观点漂移（哪条变了、为什么可能变——利益变化？新数据？）· 预验证（账本状态更新）· 立场强度变化 · 新非共识出现。同主题多人对比维度：分歧点矩阵（谁站哪边+各自利益）。
