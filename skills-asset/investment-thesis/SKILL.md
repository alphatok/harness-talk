# 投资观点推演｜多空证据与验证清单

把公司研究转成可追踪的论点与情景，供研究讨论。保留反证与不确定性，不输出没有条件的买卖指令。

## 输入与用法

提供公司/代码、研究资料、观察期限、关注问题和输出目录。例如：“用已有年报与公告比较多空情景，明确哪些证据会改变判断。”仅有名称时先搜公开一手资料；缺乏当前行情时不编现价、回撤或目标价。

## 研究流程

1. 明确主体、市场、期间与资料截止日期。优先交易所公告、法定报告和正式披露；当前价格、资本动作和规则应实时核查。公司官网属于公司陈述，不因官方身份自动证明全部宣传真实。
2. 复用用户工作区已有资料，同时检查时效。过往“已确认”不等于永久有效。新来源登记URL、发布时间/获取日、适用范围和矛盾点。不引用作者本机范本或回写其他项目。
3. 使用合法可访问的行情来源，记录币种、时区、复权、成交量单位、停牌和缺失值。没有稳定接口时请用户提供CSV；不绑定含固定参数的非正式行情API，不绕过付费或访问限制。
4. 按目标分析价格与事件；说明事件窗口、基准和其他同期因素。相关性不代表因果，“过去发生过”不自动构成可重复规律。无足够事件样本就不总结高概率规律。
5. 分别列出支持和反对论点：论点、已核实事实、推断、其他解释、推翻条件。数量按证据决定，不强凑多空各十条。不对人物动机或隐性利益关系作无依据指控。
6. 比较乐观、基准与悲观情景。说明假设、影响路径、观察指标与失效条件；概率只有在有方法和校准依据时才给数值，主观权重必须标假设。估值或价格区间仅在用户要求且输入足够时计算，列明公式和敏感性，不能用图形价位当成“确认未来”的门槛。
7. 形成催化事件与验证清单。已公告事件与预计时点分开，记录依据和观察条件。缺少公开排期不补精确日期。
8. 输出研究结论、主要反证、资料缺口和下一次核查动作。Markdown默认可直接交付；HTML可用现有工具或可选md-preview，不能依赖私人路径或特定发布服务。

## 建议交付表

| 表 | 内容 |
|---|---|
| 证据表 | 论点、来源、日期、可信边界与反证 |
| 多空对照 | 支持逻辑、反对逻辑、可观察验证条件 |
| 情景表 | 假设、机制、观察指标、失效条件与不确定性 |
| 事件表 | 已公告/预期、时间范围、依据、应验证问题 |
| 数据口径 | 来源、币种、时间、复权、单位与缺失项 |

如用户要求维护研究索引，只在指定工作区追加版本、来源和变更原因，保留旧结论。研究本身不能保证收益，也不替用户执行交易或自动发布。
