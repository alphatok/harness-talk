# Markdown阅读页｜目录、表格、图片预览

把用户指定Markdown转成同目录的 `.preview.html`，原Markdown不改动。保留章节目录、表格样式和图片放大；可用独立CSS覆盖样式。适合报告与说明阅读，不承诺支持全部Markdown方言或任意原始HTML。

## 使用

在实际技能目录执行，或使用脚本绝对路径：

```bash
python3 scripts/mdpreview.py <文件.md> --no-open
```

需要Python 3和 `markdown` 库。缺依赖时说明安装位置与方法；只在用户已授权的环境中通过标准包管理器安装，不自动往共享临时目录下载或执行依赖。Windows、macOS与Linux均可从Python入口生成文件；浏览器打开效果按当前环境验证。

默认不覆盖已有阅读页；明确更新时使用 `--overwrite`。需要自动打开时省略 `--no-open`，使用系统默认浏览器。无桌面环境可只交付文件。

## 内容与验证

- 保留相对图片路径，HTML与图片保持原目录关系；转移单个HTML不会自动打包图片。默认阻止远程图片加载，普通链接可手动访问。
- 渲染器移除原文脚本、事件属性和不支持的标签，并限制页面加载来源。复杂嵌入内容可能被省略；不是通用HTML沙箱，来源不明的复杂HTML应另行审查。
- 若同目录存在同名 `.preview.css`，将作为用户本地样式使用；只使用任务范围内的可信样式。
- 生成后核对标题、目录、表格与图片路径。浏览器不能操作时说明仅完成文件生成与结构检查，不声称视觉验收通过。
- 不启动HTTP服务、不上传、不改系统配置。输出实际生成的文件路径与已知限制。
