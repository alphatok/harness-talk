Request cancellation of a previously created outbound A2A task.

Parameters:
- `agent_name` (required): the same agent name passed to the original A2ASendMessage call.
- `task_id` (required): the taskId from a prior A2ASendMessage or A2AGetTask result.

Cancellation is a best-effort request, not a guarantee. If the task has already reached a terminal state (completed/failed/canceled/rejected), the call fails and the tool result will say so — that is expected, not an error to retry. Use A2AGetTask if you need to check the task's status before deciding whether to cancel it.

Not available inside a sub-agent or team-member session — only the main conversation can cancel outbound A2A tasks.
